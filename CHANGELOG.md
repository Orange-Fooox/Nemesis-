# История изменений

## 2026-11-27 — Синхронизация версии Unity

- Версия проекта и инструкции обновлены до Unity 6 `6000.0.85f2`, соответствующей установленному редактору.
- GitHub Actions настроен на ту же версию Unity для сборки Windows x64.
- Компиляция, Play Mode и сборка по-прежнему требуют фактического запуска в Unity Editor.

## 2026-11-27 — Unity становится основной платформой

- Unity 6 / C# закреплены как единственная целевая платформа проекта.
- Unity-проект, C#-исходники, Editor-инструменты и генераторы контента перенесены в основную ветку.
- README, Game Bible, технический статус и дорожная карта переписаны под Unity.
- История Roblox сохранена только как краткая справка о раннем этапе разработки.
- Устаревшие Roblox-файлы, Luau-исходники и Roblox-инструкции удалены из актуальной структуры репозитория.
- Runtime-проверка в Unity по-прежнему ожидается; исходники не объявляются протестированными.

## Ранее — этап прототипирования

Ранний прототип создавался на Roblox и Luau. На этом этапе проверялись базовые идеи управления, боя, генерации мира, AI и системы Немезиды. Эти наработки стали проектной основой для текущей реализации на Unity.
