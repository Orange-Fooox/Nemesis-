# История изменений

## 2026-11-27 — Подготовка архива Unity-проекта

- Добавлено автоматическое создание стартовой сцены при первом открытии Unity Editor и её добавление в Build Settings.
- Добавлен корневой .gitignore для кэшей Unity и файлов IDE.
- GitHub Actions получил отдельный job для ZIP с исходным Unity-проектом, документацией и SHA-256. Этот job не требует Unity License; Windows executable build по-прежнему требует UNITY_LICENSE.

## 2026-11-27 — Первый игровой цикл хаба

- Подсказка взаимодействия теперь показывает клавиатуру и геймпад: E или D-pad вниз.
- В стартовом greybox-прохождении запас Essence выставлен на 75/100, поэтому награда тайника +25 Essence не пропадает из-за полного ресурса.
- Добавлен Seed-генератор Пепельного Рубежа: центральная площадь, главные и районные дороги, четыре тематических района, 12 зданий, часовня, кузница, сторожевая башня, колодец и Врата Душ.
- Добавлены четыре точки появления Ash Raider и босс у Врат Душ; противники двигаются через CharacterController с учётом коллизий.
- Добавлены действия по E: диалог с Мирой и одноразовый сундук с наградой 25 Essence.
- Генерация использует импортированные безопасные Prefab, если они найдены в каталоге; в противном случае включаются локальные greybox-варианты.
- Эти системы добавлены как исходники; Unity-компиляция, проходимость хаба и Play Mode ещё не проверены.

## 2026-11-27 — Унификация ввода

- Добавлена зависимость Unity Input System 1.11.2 для Unity 6.0.
- Управление вынесено в NemesisInput: WASD/стрелки, Shift, мышь и клавиши способностей; добавлен левый стик геймпада.
- Сохранён fallback для проектов, использующих Legacy Input Manager.
- Скрипты движения, выносливости, атаки и способностей больше не вызывают старый Input API напрямую.

## 2026-11-27 — Asset catalog и первая адаптация Немезиды

- Каталогизатор ранжирует только фактические совпадения имён и пропускает визуальные Prefab/Model со встроенными MonoBehaviour-скриптами или без Renderer.
- Исправлено переключение между импортированным и placeholder-оружием, а также компоновка строки памяти Немезиды в HUD.
- Добавлена раскладка стандартных кнопок геймпада для атаки, уклонения и способностей.

- Добавлен runtime-каталог импортированных Unity Prefab/Model и Editor-сканер для Fantasy Armory и окружения.
- Персонажи могут получать импортированные шлемы, броню, оружие и щиты; тестовая арена использует найденные пропсы, сохраняя fallback-геометрию.
- Исправлена генерация тестовой сцены: используется пустая сцена, чтобы не создавать вторую Main Camera и лишний стандартный свет.
- Добавлена локальная память стиля игрока: ближние попадания, способности и уклонения.
- Ash Raider и Ashen Warlord получили ограниченные ответные модификаторы поведения.
- Эти изменения добавлены как исходники и инструменты; Unity-компиляция и runtime-проверка ещё не выполнены.

## 2026-11-27 — Синхронизация версии Unity

- Версия проекта и инструкции обновлены до Unity 6 `6000.0.85f2`, соответствующей установленному редактору.
- GitHub Actions настроен на ту же версию Unity для сборки Windows x64.
- Компиляция, Play Mode и сборка по-прежнему требуют фактического запуска в Unity Editor.

## 2026-11-27 — Unity становится основной платформой

- Unity 6 / C# закреплены как единственная целевая платформа проекта.
- Unity-проект, C#-исходники, Editor-инструменты и генераторы контента перенесены в основную ветку.
- README, Game Bible, технический статус и дорожная карта переписаны под Unity.
- История Roblox сохранена только как краткая справка о раннем этапе разработки.
- Устаревшие Roblox-файлы, Luau-исходники и Roblox-инструкции удалены из актуальной структуры репозитория.
- Runtime-проверка в Unity по-прежнему ожидается; исходники не объявляются протестированными.

## Ранее — этап прототипирования

Ранний прототип создавался на Roblox и Luau. На этом этапе проверялись базовые идеи управления, боя, генерации мира, AI и системы Немезиды. Эти наработки стали проектной основой для текущей реализации на Unity.
