# Nemesis free prototype asset library

Run **Tools → Nemesis → Generate Asset Library** in Unity Editor.

The generator creates original, locally generated prototype prefabs and material files under:
- Assets/NemesisContent/Prefabs/
- Assets/NemesisContent/Materials/

## Included generated assets

- Characters: armored player, ash raider, Ashen Warlord boss, merchant.
- Equipment: iron helm, chestplate, greatsword, shield, greaves, bone dagger, bow placeholder, crest.
- Dungeon/environment: ruined pillar, obelisk, soul flame, sarcophagus, arch fragment, stone block, rune stone, gravestone, barrel, supply crate, barricade, lantern stand, corrupted heart, ash tree parts, floor tile.

## Cost and licensing

These are original primitive-based assets generated by the project Editor script. They require no paid Asset Store package and introduce no third-party asset licensing obligations. They are greybox/low-poly placeholders, not final hand-painted or rigged pixel-art production assets.

## Importing third-party free assets later

Only import packages whose publisher explicitly grants a compatible free-use license. Keep each package's original license/attribution file beside the imported content under Assets/NemesisContent/Imported/PackageName/. Do not assume that a $0 listing automatically permits redistribution or commercial use.

## Optional free Unity Asset Store packages

These are external packages, not bundled in this repository. Add them through the Unity Asset Store while signed in, then preserve the publisher's license/attribution files under Assets/NemesisContent/Imported/.

- Lite Dungeon Pack — 28 low-poly environment assets, including walls, doors, floors, stairs, props, traps and flame; listed as free and supports URP/Built-in/HDRP: https://assetstore.unity.com/packages/3d/environments/dungeons/lite-dungeon-pack-low-poly-3d-art-by-gridness-242692
- Low Poly Dungeon - Pack — 23 ready-to-use prefabs including walls, pillars, door, floor, crates, barrels, crystals and treasure; listed as free: https://assetstore.unity.com/packages/3d/environments/dungeons/low-poly-dungeon-pack-273736
- LOW POLY Dark Fantasy Dungeon DEMO — small free sample with four prefabs and textures; useful for testing the visual direction before importing a larger pack: https://assetstore.unity.com/packages/3d/environments/dungeons/low-poly-dark-fantasy-dungeon-demo-325073

The Unity Asset Store listing/license must be checked at import time. A free listing is not permission to redistribute the original package in this Git repository. These packs have not been downloaded or imported by this automation.
