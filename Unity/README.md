# NEMESIS — Unity project

Целевая версия: **Unity 6000.0.85f2**. Язык игровой логики: **C#**.

## Открытие проекта

1. Установи Unity Hub и Unity 6000.0.85f2 с Windows Build Support.
2. В Unity Hub выбери **Add → Add project from disk** и укажи эту папку `Unity`.
3. Дождись импорта и компиляции.
4. Выполни **Tools → Nemesis → Generate Asset Library** для резервных greybox-префабов.
5. Выполни **Tools → Nemesis → Scan Imported Asset Packs**. Инструмент просканирует доступные Prefab/Model в Assets, создаст каталог и отчёт.
6. Если сцена отсутствует, выполни **Tools → Nemesis → Create Prototype Scene**.
7. Открой `Assets/Scenes/NemesisPrototype.unity` и нажми Play.

## Текущий прототип

- Изометрическая камера и управление WASD/стрелками через Unity Input System; поддерживаются клавиатура, мышь и левый стик геймпада.
- Единый адаптер ввода с резервной совместимостью для Legacy Input Manager.
- Бег, уклонение, Stamina, Essence и HP.
- Базовая ближняя атака и пять способностей.
- Ash Raider, нейтральный до получения урона.
- Ashen Warlord с преследованием, телеграфируемой атакой по области и первой реакцией на повторяющиеся привычки игрока.
- Локальная телеметрия ближних атак, способностей и уклонений; адаптация обычного врага и босса ограничена и не заменяет полноценную систему Охотников Немезиды.
- Генератор стартового хаба «Пепельный Рубеж» с Seed: центральная площадь, перекрёстные дороги, четыре района, 12 зданий, часовня, кузница, сторожевая башня, колодец и Врата Душ.
- Четыре точки появления Ash Raider, босс у Врат Душ и безопасная точка игрока.
- Взаимодействие с Мирой и одноразовым сундуком, который даёт 25 Essence. В тестовом старте герой получает 75/100 Essence, чтобы награда была полезной.
- Каталогизатор импортированных Prefab/Model: оружие, броня, щиты, колонны, стены, факелы, сундуки и другие подходящие категории автоматически привязываются по имени ресурса.
- Прототипные персонажи, торговец, экипировка и элементы окружения.
- Editor-инструменты генерации префабов, материалов и тестовой сцены.

Зависимость Input System фиксирована в Packages/manifest.json и совместима с Unity 6.0. Генерируемые модели собраны из Unity primitives и служат greybox-ресурсами. Каталогизатор использует импортированные пакеты только тогда, когда их реальные файлы уже присутствуют в Assets. Он не скачивает пакеты и не снимает ограничения лицензий. Без найденных моделей игра сохраняет безопасные fallback-визуалы.

## Сборка Windows x64

В Unity Editor выбери **Tools → Nemesis → Build Windows x64**. Результат появится в `Unity/Build/`.

Для облачной сборки используется GitHub Actions workflow `.github/workflows/unity-windows-build.yml`. Добавь секрет репозитория `UNITY_LICENSE` с действующей лицензией Unity. Workflow запускается при изменениях Unity-проекта в `main` или вручную из Actions.

## Управление

- WASD — движение
- Shift — бег
- Space — уклонение
- ЛКМ / F — обычная атака
- Z — Seal Strike
- X — Shadow Dash
- C — Earth Rend
- V — Abyss Release
- B — Barrier
- E — взаимодействие с NPC и сундуками
- Геймпад: левый стик — движение, L3 — бег, RT — атака, A — уклонение, X/Y — первые способности, LB/RB — Earth Rend/Abyss Release, B — Barrier, D-pad вниз — взаимодействие
