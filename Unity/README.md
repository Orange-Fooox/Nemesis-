# ПЕЧАТЬ БЕЗДНЫ — Unity 6

**Версия редактора:** Unity 6000.0.85f2  
**Язык:** C#  
**Платформа сборки:** Windows x64  
**Жанр:** 2D action-RPG, top-down с изометрической раскладкой

## Открыть проект

1. Установи Unity Hub и редактор 6000.0.85f2.
2. В Unity Hub нажми **Add → Add project from disk** и выбери эту папку Unity/.
3. Дождись восстановления пакетов и компиляции C#.
4. Открой Assets/Nemesis/Scenes/AshenOutskirts.unity.
5. Нажми **Play**.

Вторая игровая сцена — Assets/Nemesis/Scenes/AshenDungeon.unity.

## Что реализовано в этом срезе

- Изометрическая 2D-сцена Пепельных окраин с каменным полом, трещинами и лавовой кромкой.
- Готические здания, склеп, колонны, арка, двери, цепи, алтари, сундуки и декор.
- Отдельная сцена катакомб с процедурной планировкой комнат и переходов.
- Туман войны с обнаружением новых областей и затемнением уже посещённых.
- Перемещение героя, бег, ближняя атака, уклонение, получение урона и смерть/возрождение.
- Противники, босс, NPC, святилище, сундук и портал в подземелье.
- Русское главное меню и HUD, панель основного задания, карта, инвентарь, доска охоты, журнал и настройки.
- Направленные кадровые циклы героя Idle, Walk и Attack из 2DPIXX (CC BY 4.0): четыре направления, по четыре кадра. Hurt и Death поддерживаются процедурными реакциями.
- Сдержанная анимация окружения: два факела, группа свечей, одна шиповая ловушка и одно растение; основная масса декора статична.

## Сборка Windows

В Unity Editor выбери **Nemesis → Build Complete Windows Game**.

Либо запусти Editor в batch mode с методом:

NemesisBuild.BuildCompleteWindowsGame

Выходной каталог:

Builds/Pechat-Bezdny-Windows/Pechat_Bezdny.exe

Сборка включает обе сцены: AshenOutskirts и AshenDungeon.

## Ограничения текущего прототипа

Экран инвентаря и часть журналов пока являются интерфейсными прототипами, а не полноценными data-driven RPG-системами. Сохранения, полная экономика, характеристики и лут, готовая система заданий, аудио, полная боевая QA и тесты PlayMode остаются задачами следующих этапов. Проверка успешной компиляции и сборки не заменяет прохождение всех игровых сценариев.
