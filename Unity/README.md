# NEMESIS — Unity project

Целевая версия: **Unity 6000.0.85f2**. Язык игровой логики: **C#**.

## Открытие проекта

1. Установи Unity Hub и Unity 6000.0.85f2 с Windows Build Support.
2. В Unity Hub выбери **Add → Add project from disk** и укажи распакованную папку `Unity`.
3. Дождись импорта пакетов и компиляции скриптов.
4. При первом открытии Editor автоматически создаст `Assets/Scenes/NemesisPrototype.unity` и добавит её в Build Settings.
5. Дождись сообщения `[Nemesis] First-run scene created`, затем открой созданную сцену.
6. Выполни **Tools → Nemesis → Scan Imported Asset Packs**, чтобы подключить включённый в ZIP набор Kenney Mini Dungeon.
7. Нажми Play.

## Текущий прототип

- Изометрическая камера и управление WASD/стрелками через Unity Input System; поддерживаются клавиатура, мышь и левый стик геймпада.
- Единый адаптер ввода с резервной совместимостью для Legacy Input Manager.
- Бег, уклонение, Stamina, Essence и HP.
- Базовая ближняя атака и пять способностей.
- Ash Raider, нейтральный до получения урона.
- Ashen Warlord с преследованием, телеграфируемой атакой по области и первой реакцией на повторяющиеся привычки игрока.
- Локальная телеметрия ближних атак, способностей и уклонений; адаптация обычного врага и босса ограничена и не заменяет полноценную систему Охотников Немезиды.
- Генератор стартового хаба «Пепельный Рубеж» с Seed: центральная площадь, перекрёстные дороги, четыре района, 12 зданий, часовня, кузница, сторожевая башня, колодец и Врата Душ.
- Четыре точки появления Ash Raider, босс у Врат Душ и безопасная точка игрока.
- Взаимодействие с Мирой и одноразовым сундуком, который даёт 25 Essence. В тестовом старте герой получает 75/100 Essence, чтобы награда была полезной.
- Каталогизатор импортированных Prefab/Model: оружие, броня, щиты, колонны, стены, факелы, сундуки и другие подходящие категории автоматически привязываются по имени ресурса.
- Первый комплект внешних low-poly 3D-моделей: **Kenney Mini Dungeon 2.0 (CC0 1.0)**. В архиве находится в `Assets/NemesisContent/Imported/KenneyMiniDungeon/`.
- Дополнительные пропсы хаба: бочки и ящики у рыночного прилавка; они используют импортированные модели, если каталог находит подходящие ресурсы.
- Прототипные персонажи, торговец, экипировка и элементы окружения.
- Editor-инструменты генерации префабов, материалов, сканирования импортированных моделей и тестовой сцены.

Зависимость Input System фиксирована в Packages/manifest.json и совместима с Unity 6.0. Генерируемые модели собраны из Unity primitives и служат greybox-ресурсами. Source-archive workflow скачивает официальный Kenney Mini Dungeon 2.0 (CC0) и помещает его в Assets/NemesisContent/Imported/KenneyMiniDungeon/. После импорта Unity выполни сканирование каталога. Каталогизатор индексирует безопасные модели из этой папки и сохраняет fallback-визуалы для отсутствующих категорий.

## Сборка Windows x64

В Unity Editor выбери **Tools → Nemesis → Build Windows x64**. Результат появится в `Unity/Build/`.

Для облачной сборки используется GitHub Actions workflow `.github/workflows/unity-windows-build.yml`. Добавь секрет репозитория `UNITY_LICENSE` с действующей лицензией Unity. Workflow запускается при изменениях Unity-проекта в `main` или вручную из Actions.

## Управление

- WASD — движение
- Shift — бег
- Space — уклонение
- ЛКМ / F — обычная атака
- Z — Seal Strike
- X — Shadow Dash
- C — Earth Rend
- V — Abyss Release
- B — Barrier
- E — взаимодействие с NPC и сундуками
- Геймпад: левый стик — движение, L3 — бег, RT — атака, A — уклонение, X/Y — первые способности, LB/RB — Earth Rend/Abyss Release, B — Barrier, D-pad вниз — взаимодействие

## Проверка

ZIP содержит исходники проекта, настройки, документацию и комплект Kenney Mini Dungeon 2.0 (CC0), но не кэш Library. Unity Editor в среде подготовки исходников не запускался. Компиляция, Play Mode и Windows build требуют фактического прогона в Unity 6000.0.85f2. Не считать прототип runtime-проверенным до прохождения этих шагов.

Ранний этап разработки проходил на Roblox; краткая историческая справка сохранена в корневом README и документации миграции. Текущая разработка ведётся только на Unity.
