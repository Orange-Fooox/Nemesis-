# Ассеты: установка и лицензии

Публичный репозиторий содержит исходники и производные спрайты только тех наборов, которые разрешено включать в распространение по их лицензиям. Сторонние наборы с ограничениями на распространение не включаются.

## Уже включены

### NemesisFreeCC0

Папка: Assets/ThirdParty/NemesisFreeCC0/

Готические, dungeon- и forest-спрайты. Лицензии, README и манифесты сохранены рядом с наборами.

### RF_Catacombs

Папка: Assets/ThirdParty/NemesisCatacombs/

Набор Szadi Art. Файл public-license.txt включён: автор обозначает набор как public domain и разрешает личное и коммерческое использование. Используются отдельные детали окружения и циклические кадры факела и свечей.

## Анимации персонажа

В проекте есть state-based контроллеры NemesisHeroAnimator и NemesisEnemyAnimator. Пока они обеспечивают процедурные визуальные реакции, но утверждённые покадровые sprite sheets героя, врагов и боссов ещё не импортированы.

Будущий набор героя должен соответствовать референсу: мрачный детализированный pixel art, правильный top-down/isometric ракурс и нужные циклы по направлениям. Не подменяй его стилистически неподходящими превью.

## Локальные наборы, не включённые в Git

**CraftPix Cursed Land** не входит в публичный проект и текущей стартовой сценой не используется. При отдельной интеграции владелец проекта должен самостоятельно проверить лицензию и условия локального использования: https://craftpix.net/file-licenses/.

Не загружай платные исходники или извлечённые исходники в публичный репозиторий без явного права на распространение.
