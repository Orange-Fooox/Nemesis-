## Бой
- [ ] Базовая атака работает только по модели с тегом NemezidaEnemy.
- [ ] Нельзя атаковать цель за пределами дистанции.
- [ ] Частые запросы не обходят серверный cooldown.
- [ ] Нельзя применить способность без Essence.
- [ ] Нельзя передать произвольное имя способности и получить урон.
- [ ] Урон и провокация выставляются сервером.

## AI
- [ ] Нейтральный NPC не начинает преследование при приближении игрока.
- [ ] NPC переходит в Combat после получения урона.
- [ ] NPC наносит урон только в пределах AttackRange.
- [ ] По окончании ProvokedUntil NPC прекращает погоню и возвращается домой.
- [ ] Удаление NPC не вызывает бесконечные ошибки в цикле AI.

## Движение и камера

- [ ] Shift переключает скорость между 16 и 23.
- [ ] Сервер отклоняет некорректные типы данных RemoteEvent.
- [ ] Камера следует за персонажем и сохраняет изометрический угол после респавна.

## Известные ограничения
- Клиентский выбор цели использует Mouse.Target; полноценный target lock ещё не сделан.
- Бег пока не расходует Stamina.
- Система NemesisService хранит статистику только в памяти сервера и не сохраняет её между сессиями.
- Генератор хаба создаёт greybox-геометрию, не финальные художественные ассеты.
- Нет DataStore, инвентаря, наград, NPC, сундуков и генератора подземелий.
