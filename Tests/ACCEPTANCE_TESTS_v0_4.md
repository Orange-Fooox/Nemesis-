- [ ] Базовая атака работает только по модели с тегом NemezidaEnemy.

- [ ] Частые запросы не обходят серверный cooldown.
- [ ] Нельзя применить способность без Essence или с неизвестным именем.
- [ ] ShadowDash двигает персонажа вперёд без обязательной цели.
- [ ] EarthRend поражает нескольких врагов в радиусе вокруг выбранной цели.
