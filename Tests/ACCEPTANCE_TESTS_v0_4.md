## Бой и способности
- [ ] Базовая атака работает только по модели с тегом NemezidaEnemy.
- [ ] Нельзя атаковать цель за пределами дистанции.
- [ ] Частые запросы не обходят серверный cooldown.
- [ ] Нельзя применить способность без Essence или с неизвестным именем.
- [ ] Атаки игрока не проходят сквозь непрозрачные стены.
- [ ] ShadowDash двигает персонажа вперёд без обязательной цели.
- [ ] ShadowDash может нанести урон только допустимой цели в радиусе и с линией видимости.
- [ ] EarthRend поражает нескольких врагов в радиусе вокруг выбранной цели.
- [ ] AbyssRelease увеличивает следующий урон по цели на заданные 10% в течение 5 секунд.
- [ ] Barrier активируется без выбранного врага, создаёт щит на 4 секунды и поглощает входящий урон.
- [ ] Все способности расходуют правильное количество Essence и соблюдают cooldown.

## AI
- [ ] Нейтральный NPC не начинает преследование при приближении игрока.
- [ ] NPC переходит в Combat после получения урона.
- [ ] NPC не наносит урон сквозь стены.
- [ ] По окончании ProvokedUntil NPC прекращает погоню даже если игрок стоит рядом.
- [ ] NPC возвращается к исходной точке.
- [ ] Удаление NPC не вызывает бесконечные ошибки в цикле AI.

## Движение и камера
- [ ] WASD управляет персонажем.
- [ ] Shift переключает скорость между 16 и 23.
- [ ] Stamina расходуется при спринте и восстанавливается вне спринта.
- [ ] При нулевой Stamina спринт автоматически отключается.
- [ ] Отпускание Shift немедленно прекращает спринт.
- [ ] Камера следует за персонажем и сохраняет изометрический угол после респавна.

## Известные ограничения
- Клиентский выбор цели использует Mouse.Target; полноценный target lock ещё не сделан.
- Нет HUD-индикаторов Essence, Stamina и Barrier.
- NemesisService хранит данные только в памяти сервера; DataStore и спавн охотника не реализованы.
- Генератор хаба создаёт greybox-геометрию, не финальные художественные ассеты.
- Нет инвентаря, наград, NPC хаба, сундуков, подземелий и лута.
