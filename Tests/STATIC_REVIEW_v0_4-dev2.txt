FIXES APPLIED IN SOURCE
1. Enemy aggro expiry:
   EnemyAIService now ends the encounter as soon as ProvokedUntil expires,
   regardless of how close the player is, then returns the NPC toward its home point.
2. Line of sight:
   Server raycasts now guard player attacks and enemy attacks against hits through
   blocking geometry.
3. ShadowDash:
   The ability now applies a server-side forward impulse and does not require a target.
   A target outside range or behind an obstacle no longer prevents the dash itself.
4. EarthRend:
   The ability now damages tagged enemies in a configured radius around the selected
   enemy, with range and line-of-sight checks for each victim.
5. Barrier:
   Added B input and server ability. It grants a shield equal to 30% of MaxHealth for
   4 seconds. Enemy AI damage is absorbed by the shield before player health.
   Barrier use is recorded as a defensive action in NemesisService.
6. AbyssRelease vulnerability:
   The temporary VulnerabilityBonus is now included in subsequent server damage
   calculations while the VulnerableUntil timestamp is active.
7. Sprint stamina:
   Server drains Stamina while sprinting and regenerates it otherwise. Sprint activation
   is rate-limited, zero stamina stops the sprint, and sprint release is always accepted.
8. Nemesis telemetry:
   Confirmed player attacks/abilities and enemy encounter starts now call
   NemesisService.RecordAction / RecordEncounter.

REMAINING LIMITATIONS
- NemesisService data remains memory-only. No DataStore persistence exists.
- Nemesis hunter spawning and actual adaptive combat behavior are not implemented.
- No HUD display for Essence, Stamina, or Barrier exists yet.
- No final character/enemy models, animations, VFX, hub NPCs, chests, dungeons, loot,
  inventory, or reward system.
- Target selection still relies on Mouse.Target; no target lock.
- Server-side movement sanity/anti-teleport validation is still needed.
- The hub generator remains a greybox generator.
