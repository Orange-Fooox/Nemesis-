# Roblox Luau source — v0.4-dev.6

Исходники соответствуют текущему Place-файлу `Releases/NEMEZIDA_Studio_v0_4_dev6.rbxlx`. Перед публикацией сверяй их с Place-файлом и запускай приёмочные тесты в Roblox Studio.

## Иерархия в Studio

- `ReplicatedStorage/Nemezida/Shared/NemezidaConfig` — общие настройки.
- `ServerScriptService/Bootstrap` — автоматическая инициализация.
- `ServerScriptService/Services` — боевые сервисы, AI, генерация хаба, движение, население и Nemesis.
- `StarterPlayer/StarterPlayerScripts` — камера, бой, движение и HUD.

## Управление

- WASD — движение.
- ЛКМ или F — базовая атака.
- Z — Удар Печати.
- X — Теневой рывок.
- C — Разлом земли.
- V — Высвобождение Бездны.
- B — Барьер.
- Shift — бег с расходом выносливости.

## Запуск

Открой `Releases/NEMEZIDA_Studio_v0_4_dev6.rbxlx` через **File → Open from File** и нажми **Play (F5)**. Bootstrap выполняет стартовую настройку автоматически. Command Bar для обычного запуска не используется.

## Состав прототипа

- Изометрическая камера.
- Хаб «Пепельный Рубеж» с процедурно создаваемой геометрией.
- Безопасная точка появления и обработка респавна.
- Шесть нейтральных врагов, AI-преследование после провокации.
- Серверная базовая атака и способности с проверками цели, дальности и видимости.
- Спринт, Stamina, Essence, Barrier и HUD.

## Ограничения

Сборка остаётся dev-прототипом с greybox-геометрией и простыми моделями. Полноценные сохранения, завершённая прогрессия, лут, подземелья, NPC хаба, финальные модели, анимации и VFX не подтверждены как реализованные.

Статическая проверка XML/исходников не заменяет компиляцию Luau и запуск Roblox Studio. Runtime-приёмка, тест смерти/респавна и многопользовательская проверка обязательны.
