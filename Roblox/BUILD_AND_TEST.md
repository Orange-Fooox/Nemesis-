# Сборка и тестирование Roblox-проекта

## Что это за сборка

Репозиторий содержит Luau-исходники dev-среза v0.4 и конфигурацию Rojo. Это не экспортированный бинарный `.rbxlx`. Конфигурация собирает DataModel из исходников в правильную иерархию Roblox.

## Требования

- Roblox Studio.
- Rojo 7.x (плагин Roblox Studio и CLI).
- Git.

## Получение проекта

1. Клонируй репозиторий:
   `git clone https://github.com/valik123f-collab/Nemesis-.git`
2. Открой папку репозитория в терминале.
3. Проверь, что `default.project.json` находится в корне.
4. Запусти `rojo serve default.project.json`.
5. В Roblox Studio открой пустой Baseplate.
6. Установи плагин Rojo и подключись к локальному серверу Rojo.
7. После синхронизации проверь Explorer: ReplicatedStorage, ServerScriptService и StarterPlayerScripts должны содержать объекты из проекта.
8. Сохрани локальную копию через File → Save to File. Для обмена используй формат Roblox XML Place (`.rbxlx`).

## Первый тест

1. Нажми Play (F5).
2. В Output проверь сообщение о запуске серверных служб.
3. Проверь изометрическую камеру и WASD.
4. Проверь Shift: скорость должна переключаться между 16 и 23.
5. Проверь наличие Workspace/NemezidaGeneratedHub.
6. Для теста боя создай NPC Model с Humanoid и HumanoidRootPart, назначь PrimaryPart и добавь тег CollectionService `NemezidaEnemy`.
7. Назначь NPC числовые атрибуты: MaxHealth, Attack, Defense, WalkSpeed, DetectionRange, AttackRange, AttackCooldown.
8. Убедись, что NPC не преследует игрока до получения урона. После атаки он должен перейти в преследование.
9. Проверь Z/X/C/V по цели в радиусе и расход Essence.
10. Проверь вторым клиентом через Test → Start.

## Известные ограничения dev-среза

- Генератор хаба пока создаёт greybox, а не финальную художественную локацию.
- Модели героя и противников, HUD, анимации, NPC, сундуки, подземелья, лут и DataStore ещё не добавлены.
- Немезида пока собирает базовую статистику в памяти сервера, без долговременного сохранения и реального спавна охотника.
- Цель атаки выбирается через Mouse.Target; target lock отсутствует.
- Перед публичным релизом нужны полноценные проверки серверной валидации движения и боевых RemoteEvent.

## Критерий готовности тестового прогона

Тестовый прогон считается успешным только после того, как проект синхронизирован в Studio, Play запускается без ошибок в Output, хаб создаётся, а камера, движение, базовый бой и нейтральный AI проходят ручные проверки. Наличие исходников само по себе не является подтверждением запуска.
