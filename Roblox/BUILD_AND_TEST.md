# Сборка и тестирование Roblox-проекта

## Текущий Place-файл

**Важно: для обычного запуска команды не нужны.** Нажми только Play (F5). Script `ServerScriptService/Bootstrap` сам генерирует мир, ставит точку спавна, создаёт врагов и загружает персонажа. Файл `Tests/STUDIO_WORLD_SPAWN_TEST.lua` нужен только для дополнительной диагностики, не для старта.

Готовый XML Place для Roblox Studio находится в Roblox/Releases/NEMEZIDA_Studio_v0_4_dev5.rbxlx.

1. Скачай файл из GitHub.
2. В Roblox Studio выбери File → Open from File и укажи .rbxlx.
3. Нажми Play (F5).
4. Персонаж должен появиться на площадке хаба «Пепельный Рубеж», а не до или под геометрией.
5. Должны появиться шесть нейтральных процедурных врагов. Они начинают преследование только после получения урона.
6. HUD отображает здоровье, Essence, Stamina и Barrier.

## Что сделано для безопасного старта
- Players.CharacterAutoLoads выключается до инициализации мира.
- HubGenerator.Generate создаёт твёрдый пол и spawn-площадку до загрузки персонажей.
- NemezidaSpawn является прямым потомком Workspace; игроку задаётся Player.RespawnLocation.
- CharacterAdded перемещает персонажа на известный безопасный CFrame и обнуляет скорость.
- В случае ошибки генератора создаётся резервный пол и spawn location.
- После готовности мира автовозрождение включается обратно.

## Проверка генерации и появления
Во время Play запусти содержимое Tests/STUDIO_WORLD_SPAWN_TEST.lua из серверного Command Bar. Тест проверяет наличие NemezidaGeneratedHub, коллизионного AshenGround, прямое размещение NemezidaSpawn в Workspace, поверхность под spawn через Raycast, наличие автоматически созданных врагов с тегом NemezidaEnemy и положение персонажей игроков.

## Проверка в Studio
1. Открой View → Output и проверь отсутствие ошибок require и runtime.
2. Проверь WASD и изометрическую камеру.
3. Проверь Shift: скорость 16/23, расход и восстановление Stamina.
4. Наведи курсор на противника и атакуй ЛКМ или F.
5. Проверь Z/X/C/V/B, расход Essence и cooldown.
6. Дай врагу атаковать: Barrier должен поглощать урон в течение четырёх секунд.
7. Проверь, что нейтральные враги не агрятся до получения урона, атакуют после провокации и возвращаются после ProvokedUntil.
8. Умри и проверь, что респавн происходит на площадке.
9. Запусти второй клиент и проверь сетевое поведение.

## Rojo workflow
1. Клонируй https://github.com/valik123f-collab/Nemesis-.git.
2. Установи Rojo 7.x.
3. В корне репозитория запусти rojo serve default.project.json.
4. Подключись плагином Rojo в Roblox Studio.
5. После синхронизации проверь ReplicatedStorage, ServerScriptService и StarterPlayerScripts.
6. Для сохранения Place используй File → Save to File и формат .rbxlx.

## Ограничения
- Это dev-прототип с greybox-геометрией и простыми R6-врагами, не финальные художественные модели.
- DataStore, инвентарь, награды/полноценная прогрессия, NPC хаба, сундуки, подземелья и лут ещё не реализованы.
- Профиль NemesisService хранится только в памяти сервера; охотник Немезиды и долговременная адаптация не реализованы.
- Target lock, dodge, анимации и VFX ещё не сделаны.
- Сетевая и физическая приёмка обязательны перед публикацией.

Статический отчёт не заменяет запуск Roblox Studio. Не объявлять сборку runtime-проверенной до фактического Play-прогона.
