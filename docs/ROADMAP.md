  - Смотритель;
  - Безымянный пилигрим.
- [ ] GUI кошелька.

### AI

- [ ] Нейтральное состояние по умолчанию.
- [ ] Начальные значения `AlertUntil = 0`, `AggroRange = 0`.
- [ ] Враг реагирует на атаку игрока.
- [ ] После провокации преследует/отвечает в течение 12 секунд, затем возвращается к нейтральному поведению.

### Приёмка

- [ ] Мир создаётся без ошибок в Roblox Studio.
- [ ] Все интерактивные объекты доступны через ProximityPrompt.
- [ ] Награды выдаются сервером и не дублируются.
- [ ] Враги не преследуют игрока до провокации.
- [ ] Интерфейс кошелька обновляется после получения монет.
