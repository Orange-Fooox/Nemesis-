# Дорожная карта Unity-разработки

Целевая платформа: Unity 6, C#. Статусы отражают наличие исходников, а не автоматически подтверждённую работоспособность.

## Этап 1 — базовый вертикальный срез

- [x] Создать Unity-проект и структуру C#-исходников.
- [x] Добавить изометрическую камеру и управление.
- [x] Добавить ресурсы HP, Stamina и Essence.
- [x] Добавить бег и уклонение.
- [x] Добавить базовую атаку и пять способностей.
- [x] Добавить прототип обычного врага и босса.
- [x] Добавить Editor-инструменты генерации тестовой сцены и библиотеки префабов.
- [ ] Открыть проект в Unity Editor, исправить ошибки компиляции и проверить Play Mode.
- [ ] Подтвердить Windows x64 build.

## Этап 2 — боевой фундамент

- [ ] Единая система урона, попаданий, хитбоксов и неуязвимости.

- [ ] Телеграфы атак, реакция на попадание, оглушение и смерть.
- [ ] Полноценные анимации и VFX.
- [ ] EditMode и PlayMode тесты.

- [ ] Проверка связности, коллизий, точек входа и выхода.

## Принцип ведения статуса

Галочка означает, что соответствующие исходники или инструменты добавлены в репозиторий. Она не заменяет проверку в Unity Editor. Все непроверенные функции должны оставаться явно помеченными как требующие компиляции или runtime-теста.
