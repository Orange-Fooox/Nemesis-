# Технический статус проекта

Обновлено: 2026-11-27  
Целевая платформа: **Unity 6 — 6000.0.85f2**  
Язык: **C#**

## Текущая база

В каталоге `Unity/` находится исходная реализация игрового прототипа, Editor-инструменты и конфигурация импортированных ассетов. Структура исходного проекта и упаковка ZIP проверены в GitHub Actions. Фактическая компиляция и запуск в Unity Editor ещё не подтверждены.

### Реализовано в исходниках

- Изометрическая камера и движение WASD относительно направления камеры.
- Бег с расходом и восстановлением Stamina, уклонение с затратой Stamina.
- HP, Stamina и Essence.
- Ближняя атака и способности Seal Strike, Shadow Dash, Earth Rend, Abyss Release и Barrier.
- Ash Raider: нейтральное состояние до получения урона, затем преследование и атака.
- Ashen Warlord: повышенный запас здоровья, преследование и телеграфируемая атака по области.
- HUD прототипа.
- Генератор хаба «Пепельный Рубеж» с фиксированным Seed, четырьмя районами, 12 зданиями, дорогами, центральной площадью, ориентирами и четырьмя точками спавна врагов.
- Взаимодействие по E: диалог с Мирой и одноразовый тайник, восстанавливающий 25 Essence; стартовый запас в greybox-сцене — 75/100.
- Единый адаптер ввода для Unity Input System с Legacy Input Manager fallback.
- Локальная телеметрия ближних атак, использования способностей и уклонений.
- Первая ограниченная адаптация врагов, основанная на повторяющихся действиях игрока.
- Каталог импортированных Prefab/Model, Editor-сканер и runtime-выбор безопасных визуальных ресурсов.
- Editor-генераторы тестовой сцены, префабов и материалов.
- Дополнительные бочки и ящики в торговой зоне, которые используют импортированные модели, когда они доступны.

## Импортированный контент

В артефакт Unity ZIP включён **Kenney Mini Dungeon 2.0**:

- 30 GLB-моделей: человек и орк с анимациями, сундук, ворота, колонны, стены, пол, лестницы, бочки, меч, копьё, щиты и дополнительные пропсы.
- Общая colormap-текстура.
- Оригинальный `License.txt` от автора.
- Лицензия: **Creative Commons Zero 1.0 Universal (CC0)**, использование в коммерческих проектах разрешено, указание авторства не обязательно.

Официальная страница набора: https://kenney.nl/assets/mini-dungeon

Пакет `com.unity.cloud.gltfast` версии **6.21.0** добавлен в `Packages/manifest.json`, чтобы Unity импортировала GLB как нативные ассеты. Source-archive workflow скачивает оригинальные файлы из закреплённого публичного GitHub mirror commit и помещает их в:

`Assets/NemesisContent/Imported/KenneyMiniDungeon/`

Загрузчик также используется в Windows build job. В CI успешно прошла загрузка 30 GLB, проверка структуры и упаковка ZIP. Исходные бинарные модели не хранятся в основной Git-истории, они добавляются в сборочный ZIP при создании артефакта.

После открытия проекта в Unity требуется дождаться импорта glTFast и выполнить **Tools → Nemesis → Scan Imported Asset Packs**. Сканер явно перечисляет GLB/GLTF в папке Imported и выбирает подходящие модели по ключевым словам.

## Генерируемые прототипные ресурсы

Editor-инструмент создаёт заготовки персонажа, Ash Raider, Ashen Warlord, торговца, экипировки и элементов окружения. Это геометрия из Unity primitives для greybox и проверки игровых систем, а не финальный художественный набор. Импортированные модели постепенно заменяют часть таких заглушек.

## Не подтверждено

- Компиляция проекта внутри Unity Editor 6000.0.85f2.
- Запуск и прохождение Play Mode.
- Фактический выбор всех моделей каталогизатором, правильность их масштаба, ориентации и материалов.
- Применение анимаций GLB через Unity Animator и корректность rig retargeting.
- Успешная сборка Windows x64. Последний CI build job завершился до запуска редактора из-за отсутствующего секрета `UNITY_LICENSE`; это не результат компиляции C#.
- Полноценный боевой хитдетект, VFX, звук и финальные анимационные контроллеры.
- Инвентарь, экипировка с реальными характеристиками, лут и сохранения.
- Runtime-проверка проходимости всех районов и расстановки коллизий; генератор модульных подземелий ещё не реализован.
- Долгосрочная память, полноценный Nemesis Hunter director и сохранение хроники соперников.
- Сетевая игра и облачные сохранения.

## Следующие этапы

1. Открыть проект в Unity, дождаться установки Input System и glTFast, устранить ошибки компиляции.
2. Сгенерировать стартовую сцену и выполнить сканирование 30 GLB.
3. Проверить модель персонажа, кости, анимации, оружие, масштаб и текстуры.
4. Завершить базовый боевой цикл: попадания, урон, смерть, награда и перезапуск боя.
5. Собрать небольшое модульное подземелье с комнатами, переходами, ловушками и боссом.
6. Добавить инвентарь, экипировку, добычу, сохранение прогресса и полноценную систему Немезиды.
7. Пройти тесты в Editor/Play Mode, затем получить Windows x64 build.

## Технические правила

1. Не помечать функцию как готовую, пока она не собрана и не проверена в Unity.
2. Игровая логика должна быть отделена от визуальных компонентов.
3. Баланс врагов, предметов и способностей переносить в data-driven конфигурации и ScriptableObjects.
4. Случайная генерация должна быть воспроизводимой по Seed.
5. Сначала собрать и проверить одиночный вертикальный срез, затем расширять мир и систему Немезиды.
