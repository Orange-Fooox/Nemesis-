# Система Немезиды

## Видение
Немезида — центральная системная особенность игры. Мир запоминает значимые действия игрока, формирует соперников и создаёт последствия. Система не должна быть нечестным «читером»: она не читает ввод, не отменяет способности и не делает врагов неуязвимыми.

## Подсистемы
1. Encounter Memory — агрегированная память столкновений.
2. Combat Adaptation — ограниченная адаптация особых врагов.
3. Nemesis Hunter — процедурно создаваемые охотники.
4. Regional Threat — угроза региона.
5. Nemesis Chronicle — история личных соперников и значимых побед.

## Память столкновений
Сохраняются агрегаты, а не каждое нажатие клавиши:
- доля атак ближнего/дальнего боя;
- частота уклонений и блоков;
- предпочитаемая дистанция;
- часто применяемые способности;
- типы побеждённых элитных врагов;
- исходы значимых столкновений.

Данные имеют ограниченный срок актуальности и могут затухать, чтобы старый стиль игрока не преследовал его бесконечно.

## Адаптация
| Поведение игрока | Ответ врага |
|---|---|
| Частые уклонения | Атаки с задержкой или зоной |
| Постоянный блок | Тяжёлые пробивающие удары |
| Дальняя дистанция | Рывки и дальние снаряды |
| Частые критические удары | Защитная стойка |
| Повтор одного умения | Ситуативная защита от этого паттерна |

Максимальное дополнительное сопротивление от адаптации: 20%. Адаптация должна быть читаемой по анимации и телеграфу атаки.

## Охотник Немезиды
Проектный базовый профиль:
- HP 650;
- ATK 55;
- DEF 20;
- скорость 17;
- уровень игрока +2;
- награда 220 XP;
- базовый шанс появления после подходящего события 10%.

Процедурные свойства:
- имя и титул;
- внешний вид из разрешённых частей;
- оружие и боевой архетип;
- одна особая способность;
- до двух модификаторов;
- таблица наград;
- история встреч.

Охотник должен иметь уникальный идентификатор и сохраняться, если он стал долгосрочным соперником.

## Угроза региона
Threat — целое число от 0 до 100.

| Значение | Состояние |
|---|---|
| 0–19 | Спокойствие |
| 20–39 | Беспокойство |
| 40–59 | Усиленные патрули |
| 60–79 | Элитные угрозы |
| 80–99 | Вторжения |
| 100 | Региональное событие |

Угроза растёт от проваленных событий, активированных разломов и иных заданных триггеров. Она снижается от уничтожения источников заражения, побед над региональными боссами и специальных заданий. Не следует повышать Threat просто за обычную игру без понятной причины.

## Модификаторы врагов
| Модификатор | Эффект |
|---|---|
| Кровожадный | +15% ATK, -5% DEF |
| Панцирный | +25% DEF, -10% скорости |
| Искажённый | +20% HP, +10% теневого урона |
| Неумолимый | +15% скорости |
| Пожиратель душ | лечится на 5% нанесённого урона |

Обычному врагу — максимум 2 модификатора; элитному — максимум 3. Модификаторы выбираются из совместимых групп, чтобы не создавать сломанные комбинации.

## Защита от злоупотреблений
- Сервер хранит авторитетные данные.
- Клиент не может назначать себе Threat, награды или характеристики охотника.
- Ограничить частоту создания охотников.
- Не выдавать награду повторно за один и тот же EncounterId.
- Сохранять версию схемы данных для миграций.
