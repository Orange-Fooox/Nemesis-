# Оружие, броня и экипировка

Все числа — проектные базовые параметры до бонусов редкости, улучшений и характеристик героя.

## Формула атаки
Attack = HeroBaseATK + WeaponDamage. Итоговый урон навыка рассчитывается по общей формуле боя. AttackSpeed — рекомендуемое количество атак в секунду.

## Редкость
| Редкость | Цвет | Множитель параметров |
|---|---|---:|
| Обычный | Серый | ×1.00 |
| Необычный | Зелёный | ×1.05 |
| Редкий | Синий | ×1.10 |
| Эпический | Фиолетовый | ×1.18 |
| Легендарный | Золотой | ×1.28 |
| Мифический | Красный | ×1.40 |

Множитель применяется к параметрам предмета, для которых это разрешено балансом. Уникальные эффекты не должны автоматически масштабироваться.

## Общие поля предмета
ItemId, DisplayName, Slot, Rarity, RequiredLevel, WeaponDamage, AttackSpeed, CriticalChance, Range, StaminaCost, Element, Defense, HealthBonus, Resistances, SpecialEffect, UpgradeLevel.

## Принципы баланса
- Медленное оружие должно компенсировать скорость высоким уроном, контролем или пробитием.
- Быстрое оружие должно иметь меньший урон за удар.
- Бонус против конкретного типа врагов должен быть полезным, но не обязательным.
- Мифическая редкость не должна делать базовый контент тривиальным.
- Итоговые числа корректируются после плейтестов.
